ACM 常用数学结论研究笔记：组合、数论、图计数与博弈速查

发表于 2026-10-19 更新于 2026-10-23 分类于 数学 5364 字 约 14 分钟

这是一份面向算法竞赛（ACM / ICPC / 蓝桥杯 / 考研机试）的常用数学结论与模型触发速查手册，涵盖组合计数、数论、图论计数、博弈论、线性代数、多项式与卷积、几何与平面图、概率与期望八大板块，并在文末附带「题面信号 $\to$ 优先联想」的考场识别清单。

💡 使用方式

  • 不要只背名字：重点记「看到什么题面模型，该联想到什么数学结论」。
  • 先掌握 Catalan、Ballot、Raney、容斥、Lucas、CRT、Möbius、Burnside、SG、矩阵树这些高频结论。
  • 每个结论至少配 2～3 道题练手，否则比赛时很难从题面识别出来。
  • 公式里的除法在模质数下通常写成乘逆元；组合数要提前确认预处理范围。

📊 优先级速览

优先级 核心结论 为什么重要
🔥 必会 Catalan、Ballot、容斥、Lucas、CRT、扩展欧几里得、Nim / SG 出现频率极高，模板化强，银牌区间经常直接考
⭐ 强烈建议 Raney / 循环引理、Burnside / Pólya、Möbius 反演、矩阵树定理、Prüfer 序列 属于“见过就很快，没见过很难现场造”的结论
🚀 进阶 杜教筛、二次剩余、BEST 定理、拉格朗日插值、FWT、生成函数 多校、区域赛、强校联训里常用于拉开区分度

一、 组合计数

1. Catalan 数（卡特兰数）

  • 模型触发：
    • 合法括号序列、栈的合法出栈序列；
    • 网格路径不越过对角线；
    • 二叉树形态计数、凸多边形三角剖分。
  • 核心公式：
    $$\mathrm{Cat}_n = \frac{1}{n+1}\binom{2n}{n} = \binom{2n}{n} - \binom{2n}{n+1}$$
  • 常见用途：判断前缀合法的序列计数；把“不越界”路径转成反射法（折线法）。
  • 注意点：严格区分严格不越过与不超过边界的偏移量差别。

2. Ballot 定理（投票定理 / Bertrand Ballot）

  • 模型触发：$A$ 与 $B$ 的票数/步数固定（$a > b$），要求 $A$ 全程严格领先 $B$（等价于一维前缀和始终为正）。
  • 核心公式：
    $$\text{严格领先方案数} = \frac{a - b}{a + b}\binom{a + b}{b}$$
    （非严格领先常可转为 Catalan 或反射法。）
  • 常见用途：投票、路径不穿线、比赛比分全程领先。

3. Raney 引理（循环引理 / Cycle Lemma）

  • 模型触发：
    • 一串步长总和为正，要求所有前缀和均为正；
    • 允许步长不是简单的 $+1/-1$（例如 $+1$ 与 $1-c$）；
    • 题面出现“初始资源 $n$、中途不能耗尽、最后刚好归零”时优先联想。
  • 核心公式：
    • 若整数序列 $x_i \le 1$ 且 $\sum_{i=1}^m x_i = r > 0$，则其所有 $m$ 个循环移位中恰有 $r$ 个满足前缀和全为正。
    • 常见合法数模型：$\frac{n}{m}\binom{m}{k}$。
  • 注意点：循环类大小通常是 $m$；若序列有周期，用标准引理处理，不要手动乱除。

4. 容斥原理（Inclusion-Exclusion Principle）

  • 模型触发：要求“至少一个条件满足”或“没有任何条件满足”；限制很多但每个限制子集单独计算容易。
  • 核心公式：
    $$\left|\bigcup_{i=1}^n A_i\right| = \sum_i |A_i| - \sum_{i<j}|A_i \cap A_j| + \sum_{i<j<k}|A_i \cap A_j \cap A_k| - \cdots$$
    （求“恰好 $k$ 个满足”常用二项式反演形式。）

5. 错排公式（Derangement）

  • 模型触发：$n$ 个元素排列，要求每个元素都不在原来的位置（$\pi_i \ne i$）。
  • 核心公式：
    $$D_n = n! \sum_{i=0}^n \frac{(-1)^i}{i!}, \qquad D_n = (n-1)(D_{n-1} + D_{n-2})$$

6. Lucas 定理

  • 模型触发：$n, m$ 很大（如 $10^{18}$），模数 $p$ 是较小质数，求 $\binom{n}{m} \bmod p$。
  • 核心公式：
    $$\binom{n}{m} \equiv \prod_i \binom{n_i}{m_i} \pmod p$$
    其中 $n_i, m_i$ 是 $n, m$ 在 $p$ 进制下的各位数字。
  • 注意点：模数必须是质数；合数模数要拆 CRT 或用扩展 Lucas（exLucas）。

7. Vandermonde 恒等式（范德蒙德卷积）

  • 模型触发：组合数卷积，左右两部分各选若干个，总共选 $n$ 个。
  • 核心公式：
    $$\sum_i \binom{a}{i}\binom{b}{n-i} = \binom{a+b}{n}$$

8. Burnside 引理与 Pólya 计数

  • 模型触发：旋转、翻转、置换后视为同一种方案，问本质不同的染色、排列或图形数量。
  • 核心公式：
    $$\text{本质不同方案数} = \frac{1}{|G|} \sum_{g \in G} |X^g|$$
    即“所有群作用下的不动点数量之和 $\div$ 群大小”。在 $m$ 色染色问题中，置换 $g$ 的不动点数为 $m^{c(g)}$（$c(g)$ 为置换环个数）。
  • 注意点：必须明确“哪些变换视为相同”（仅旋转 vs 旋转+翻转，群大小 $|G|$ 不同）。

9. Stirling 数与 Bell 数（斯特林数与贝尔数）

  • 模型触发：把 $n$ 个不同元素分成 $k$ 个非空无序组（第二类斯特林数）；或将 $n$ 个元素排成 $k$ 个轮换（第一类斯特林数）。
  • 核心公式：
    $$\left\{ \begin{matrix} n \\ k \end{matrix} \right\} = \left\{ \begin{matrix} n-1 \\ k-1 \end{matrix} \right\} + k \left\{ \begin{matrix} n-1 \\ k \end{matrix} \right\}, \qquad B_n = \sum_{k=0}^n \left\{ \begin{matrix} n \\ k \end{matrix} \right\}$$

10. 隔板法（Stars and Bars）

  • 模型触发：把 $n$ 个相同物品分给 $k$ 个不同盒子（不定方程整数解个数）。
  • 核心公式：
    • 非负整数解（$x_1 + \cdots + x_k = n,\; x_i \ge 0$）：$\displaystyle\binom{n+k-1}{k-1}$
    • 正整数解（$x_1 + \cdots + x_k = n,\; x_i \ge 1$）：$\displaystyle\binom{n-1}{k-1}$
    • 若有上界限制 $x_i \le u_i$，通常结合容斥原理。

二、 数论

1. 费马小定理与欧拉定理

  • 费马小定理（$p$ 为质数，$\gcd(a, p) = 1$）：
    $$a^{p-1} \equiv 1 \pmod p \implies a^{-1} \equiv a^{p-2} \pmod p$$
  • 欧拉定理（任意模数 $m$，$\gcd(a, m) = 1$）：
    $$a^{\varphi(m)} \equiv 1 \pmod m$$

2. 扩展欧几里得（exgcd）与中国剩余定理（CRT / EXCRT）

  • exgcd：求解 $ax + by = \gcd(a, b)$；$a$ 在 $\bmod m$ 下有逆元 $\iff \gcd(a, m) = 1$。
  • CRT / EXCRT：合并同余方程组 $x \equiv a_i \pmod{m_i}$。模数不互质时用 EXCRT 逐条通过 exgcd 合并，必须检查 $(a_i - a_j)$ 能否被 $\gcd(m_i, m_j)$ 整除。

3. Möbius 反演（莫比乌斯反演）

  • 模型触发：出现 $\gcd$、互质对计数、约数求和；已知 $F(n) = \sum_{d \mid n} G(d)$ 求 $G(n)$。
  • 核心公式：
    $$G(n) = \sum_{d \mid n} \mu(d)\,F\!\left(\frac{n}{d}\right), \qquad [\gcd(i, j) = 1] = \sum_{d \mid \gcd(i, j)} \mu(d)$$
  • 常见搭档：线性筛预处理 $\mu$ 前缀和 + 整除分块 $\mathcal{O}(\sqrt{n})$ 单次查询。

4. Wilson 定理与二次剩余

  • Wilson 定理：$(p-1)! \equiv -1 \pmod p \iff p$ 是质数。
  • 二次剩余（Euler 判别法）：对奇质数 $p$，方程 $x^2 \equiv a \pmod p$ 有非零解当且仅当
    $$a^{\frac{p-1}{2}} \equiv 1 \pmod p$$
    （求根可使用 Cipolla 或 Tonelli–Shanks 算法。）

三、 图论计数

1. Cayley 公式与 Prüfer 序列

  • Cayley 公式：$n$ 个带标号顶点的无根树总数为 $n^{n-2}$（完全图 $K_n$ 的生成树个数）。
  • Prüfer 序列：带标号无根树与长度为 $n-2$、值域 $[1, n]$ 的序列一一对应，且点 $i$ 的度数 $d_i = (\text{序列中 } i \text{ 出现的次数}) + 1$。
  • 给定度数序列的树数量：
    $$\frac{(n-2)!}{\prod_{i=1}^n (d_i - 1)!}$$

2. 矩阵树定理（Kirchhoff 定理）

  • 模型触发：求一般无向图/有向图的生成树数量（或边权乘积之和）。
  • 核心公式：构造拉普拉斯矩阵 $L = D - A$（即 $L_{ii} = \deg(i)$，$L_{ij} = -\text{edge\_count}(i, j)$），删去任意第 $k$ 行和第 $k$ 列后的主子式行列式 $\det(L^{(k)})$ 即为生成树数量。

四、 博弈论

1. Nim 异或定理与 SG 函数（Sprague–Grundy 定理）

  • Nim 定理：$n$ 堆石子 $a_1, \dots, a_n$，先手必败当且仅当
    $$a_1 \oplus a_2 \oplus \cdots \oplus a_n = 0.$$
  • SG 函数：在公平组合游戏（ICG）中，定义
    $$\mathrm{SG}(x) = \mathrm{mex}\{\mathrm{SG}(y) \mid x \to y\}, \qquad \mathrm{SG}_{\text{总}} = \mathrm{SG}(x_1) \oplus \mathrm{SG}(x_2) \oplus \cdots \oplus \mathrm{SG}(x_k).$$

五、 线性代数、多项式与几何

1. 线性代数三剑客

  • 高斯消元：实数/模数解方程、树/图上随机游走概率期望方程；$\mathbb{F}_2$ 异或方程组常用 std::bitset 优化至 $\mathcal{O}(n^3 / w)$。
  • 矩阵快速幂：状态转移固定，求第 $n$ 项或走 $n$ 步后的状态 $F_n = A^n F_0$。
  • 异或线性基：维护 $\mathbb{F}_2$ 下的一组极大线性无关组，支持 $\mathcal{O}(\log V)$ 插入、最大/最小异或查询、第 $k$ 小异或查询。

2. 多项式与卷积

  • NTT / FFT：加速加法卷积 $c_k = \sum_{i} a_i b_{k-i}$（常用 NTT 模数 $998244353$，原根 $g = 3$）。
  • FWT（快速沃尔什变换）：加速位运算卷积 $c_k = \sum_{i \odot j = k} a_i b_j$（其中 $\odot \in \{\mathrm{OR}, \mathrm{AND}, \mathrm{XOR}\}$）。
  • 拉格朗日插值：$n$ 次多项式由 $n+1$ 个点值唯一确定；若横坐标连续取值 $1 \dots n+1$，可 $\mathcal{O}(n)$ 求出任意单点 $f(k)$。

3. 几何与平面图

  • 鞋带公式（Shoelace Formula）：简单多边形面积 $2S = \left|\sum_{i=1}^n (x_i y_{i+1} - x_{i+1} y_i)\right|$。
  • Pick 定理：顶点均为整点的简单格点多边形，面积 $S = I + \frac{B}{2} - 1$（$I$ 为内部格点数，$B$ 为边界格点数）。
  • 平面图欧拉公式：连通平面图满足 $V - E + F = 2$（若含 $c$ 个连通块则为 $V - E + F = c + 1$）。

4. 概率与期望

  • 期望线性性：$\mathbb{E}[X + Y] = \mathbb{E}[X] + \mathbb{E}[Y]$（不要求独立！常把全局复杂期望拆成每个元素/每条边/每个位置的指示器变量 $0/1$ 贡献概率之和）。
