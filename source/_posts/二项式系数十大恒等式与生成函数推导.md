> **出处**：R. Graham, D. Knuth, O. Patashnik, *Concrete Mathematics*（《具体数学》）第 2 版，第 5 章 “Binomial Coefficients”，**Table 174 — The top ten binomial coefficient identities**（第 174 页）。书中原话：*“Table 174 collects ten of the most useful formulas, all in one place; these are the best identities to know.”*

本文抄录这十条最重要的二项式系数恒等式，并给出用 **生成函数（母函数）** 推导的完整过程。少数几条是“生成函数的输入”（如二项式定理本身），改用求导或组合双计数，但核心思路完全一致：**把恒等式翻译成母函数的代数恒等式，再比较系数**。文中所有公式均已用程序对 $n \le 9$ 等小参数做过全量数值验证（8757 组检查全部通过）。

## 0. 记号与两个核心动作

| 记号 | 含义 |
| :--- | :--- |
| $\binom{n}{k}$ | 二项式系数；$n$ 可为任意实数/复数，$k$ 为非负整数 |
| $A(x) = \sum a_n x^n$ | 数列 $(a_n)$ 的普通生成函数（OGF） |
| $[x^n]A(x)$ | 提取幂级数 $A(x)$ 中 $x^n$ 的系数 |
| $\mathrm{CT}_z\,F(z)$ | 常数项（Constant Term），即 $[z^0]F(z)$ |

**两个核心动作（下文反复使用）：**

- **下标之和为定值** $\implies$ 母函数 **【相乘】**（卷积）
- **下标【相等】** $\implies$ 取 **【常数项】** $\mathrm{CT}_z$

记住这两条，一大半的组合恒等式都能机械地推出来。

## 1. 速查表：Table 174 十条恒等式

| # | 恒等式 | 条件 | 名称 |
| :---: | :--- | :--- | :--- |
| **1** | $\displaystyle\binom{n}{k} = \frac{n!}{k!\,(n-k)!}$ | 整数 $n \ge k \ge 0$ | 阶乘展开（factorial expansion） |
| **2** | $\displaystyle\binom{n}{k} = \binom{n}{n-k}$ | $n \ge 0$，$k$ 为整数 | 对称性（symmetry） |
| **3** | $\displaystyle\binom{r}{k} = \frac{r}{k}\binom{r-1}{k-1}$ | $k \ne 0$ 为整数 | 吸收/提取（absorption / extraction） |
| **4** | $\displaystyle\binom{r}{k} = \binom{r-1}{k} + \binom{r-1}{k-1}$ | $k$ 为整数 | 加法/归纳（addition / induction） |
| **5** | $\displaystyle\binom{r}{k} = (-1)^k\binom{k-r-1}{k}$ | $k$ 为整数 | 上指标取负（upper negation） |
| **6** | $\displaystyle\binom{r}{m}\binom{m}{k} = \binom{r}{k}\binom{r-k}{m-k}$ | $m, k$ 为整数 | 三项式改写（trinomial revision） |
| **7** | $\displaystyle\sum_k \binom{r}{k} x^k y^{r-k} = (x+y)^r$ | $r \ge 0$ 整数，或 $\lvert x/y\rvert < 1$ | 二项式定理（binomial theorem） |
| **8** | $\displaystyle\sum_{k \le n} \binom{r+k}{k} = \binom{r+n+1}{n}$ | $n$ 为整数 | 平行求和（parallel summation） |
| **9** | $\displaystyle\sum_{0 \le k \le n} \binom{k}{m} = \binom{n+1}{m+1}$ | $m, n \ge 0$ 为整数 | 上指标求和（upper summation） |
| **10** | $\displaystyle\sum_k \binom{r}{k}\binom{s}{n-k} = \binom{r+s}{n}$ | $n$ 为整数 | **范德蒙德卷积**（Vandermonde convolution） |

> **结构总结**：第 1–6 条是“改写单个二项式系数”的工具（**刀**），第 7–10 条是“求和公式”（**模子**）。实战流程永远是：**先用 1–6 把式子整形成 7–10 能套的样子，再套公式。**

## 2. 生成函数工具箱

### 2.1 武器 A：二项式定理（母函数本体）——即第 7 条

$$(1 + z)^r = \sum_k \binom{r}{k} z^k$$

这是一切推导的出发点：所有的二项式系数，就是 $(1+z)^r$ 展开后的系数。允许 $r$ 为任意实数/复数（形式幂级数意义下，不需要收敛性）。

### 2.2 武器 B：卷积 = 乘法

$$\sum_k a_k b_{n-k} = [z^n]\,A(z)B(z)$$

这是“下标和为定值”型求和的万能钥匙：只要看到指标形如 $k$ 与 $n-k$ 配对，就写成两个母函数相乘。

### 2.3 武器 C：常数项技巧（处理“下标相等”）

$$\sum_k a_k b_k = \mathrm{CT}_z\,A(z)\,B\!\left(\frac{1}{z}\right)$$

这是“下标相同”型求和的钥匙。因为 $\mathrm{CT}_z\,z^j = [j = 0]$：

$$\mathrm{CT}_z\,A(z)B(1/z) = \mathrm{CT}_z \left(\sum_j a_j z^j\right)\left(\sum_i b_i z^{-i}\right) = \sum_{j-i=0} a_j b_i = \sum_k a_k b_k.$$

### 2.4 武器 D：负指数与 $\frac{1}{(1-z)}$ 家族

$$\frac{1}{(1-z)^{m+1}} = \sum_{k \ge 0} \binom{m+k}{k} z^k$$

配合“乘 $\frac{1}{1-z} =$ 前缀和”，就是后面第 8、9 条的推导工具：

$$\sum_n \left(\sum_{k \le n} a_k\right) z^n = \frac{A(z)}{1 - z}.$$

### 2.5 武器 E：求导（造出因子 $k$）

$$A'(z) = \sum_k k\,a_k z^{k-1}.$$

用于第 3 条（吸收恒等式）——把“外面的 $k$”吸收进系数里。

## 3. 逐条推导

### (1) 阶乘展开（factorial expansion）——定义

$$\binom{n}{k} = \frac{n!}{k!\,(n-k)!} \quad (n \ge k \ge 0)$$

这是定义，不需要推导。它由武器 A 在 $r = n$ 为自然数时的 Taylor 系数给出：

$$\left.\frac{1}{k!}\frac{\mathrm{d}^k}{\mathrm{d}z^k}(1+z)^n\right|_{z=0} = \frac{n(n-1)\cdots(n-k+1)}{k!} = \frac{n!}{k!\,(n-k)!}.$$

对一般实数/复数 $r$ 则推广为 $\binom{r}{k} = \frac{r^{\underline{k}}}{k!}$（下降阶乘），这就是**广义二项式系数**。

### (2) 对称性（symmetry）——第 2 条

$$\binom{n}{k} = \binom{n}{n-k}$$

- **方法一（代数）**：直接由阶乘表达式，分母对 $k \leftrightarrow n-k$ 对称。
- **方法二（组合）**：从 $n$ 个元素里选 $k$ 个 $\equiv$ 从 $n$ 个里“留下 $n-k$ 个不选”。
- **方法三（母函数视角）**：由武器 A，$\binom{n}{k} = [z^k](1+z)^n$，而
  $$\binom{n}{n-k} = [z^{n-k}](1+z)^n = [z^k]\,z^n(1+z^{-1})^n,$$
  两个表达式本质相同（回想武器 C：$A(z)$ 与 $A(1/z)$ 通过常数项配对）。

### (3) 吸收/提取（absorption / extraction）——第 3 条

$$\binom{r}{k} = \frac{r}{k}\binom{r-1}{k-1}$$

**生成函数证明（用武器 E：求导）**：对 $(1+z)^r = \sum_k \binom{r}{k} z^k$ 两边求导：

$$r(1+z)^{r-1} = \sum_k k\binom{r}{k} z^{k-1}$$

左边用武器 A（指数换成 $r-1$）展开：$r(1+z)^{r-1} = r\sum_j \binom{r-1}{j} z^j$。比较两边 $z^{k-1}$ 的系数：

$$r\binom{r-1}{k-1} = k\binom{r}{k} \implies \binom{r}{k} = \frac{r}{k}\binom{r-1}{k-1}.$$

> **用途**：当求和号外面挂了因子 $k$（或分母上有 $k$）时，用它把 $k$ “吸收”进二项式系数，使其变成 Table 174 里可套用的形状。等价形式：$k\binom{n}{k} = n\binom{n-1}{k-1}$。

### (4) 加法/归纳（addition / induction）——第 4 条

$$\binom{r}{k} = \binom{r-1}{k} + \binom{r-1}{k-1}$$

**生成函数证明（一步）**：由 $(1+z)^r = (1+z)^{r-1} \cdot (1+z)$，两边取 $[z^k]$：

$$[z^k](1+z)^r = [z^k](1+z)^{r-1} + [z^{k-1}](1+z)^{r-1}$$

即得。这正是 Pascal 三角的递推，也是“归纳法证明恒等式”时能奏效的原因（把上指标 $r$ 降到 $r-1$，递归结构完美匹配归纳假设）。

### (5) 上指标取负（upper negation）——第 5 条

$$\binom{r}{k} = (-1)^k \binom{k-r-1}{k}$$

**生成函数证明（用武器 D）**：先看两个母函数：
- 由武器 A：$\sum_k \binom{r}{k}(-z)^k = (1-z)^r$，即 $\sum_k (-1)^k \binom{r}{k} z^k = (1-z)^r$。
- 把武器 D 中的 $m$ 换成 $-r-1$：$\sum_k \binom{k-r-1}{k} z^k = \frac{1}{(1-z)^{-r}} = (1-z)^r$。

两个级数相等，比较 $z^k$ 系数即得 $(-1)^k\binom{r}{k} = \binom{k-r-1}{k}$。

> **用途**：把负的上指标“翻”成正的，或把上指标里的变量挪到条件里。它是“求和范围自动截断”的关键——当 $k-r-1 \ge 0$ 时右边才可能非零，等价于自动限制了 $k > r$ 时左边为 $0$。

### (6) 三项式改写（trinomial revision）——第 6 条

$$\binom{r}{m}\binom{m}{k} = \binom{r}{k}\binom{r-k}{m-k}$$

**代数验证（两次阶乘展开）**：

$$\binom{r}{m}\binom{m}{k} = \frac{r!}{m!\,(r-m)!}\cdot\frac{m!}{k!\,(m-k)!} = \frac{r!}{k!\,(m-k)!\,(r-m)!},$$

$$\binom{r}{k}\binom{r-k}{m-k} = \frac{r!}{k!\,(r-k)!}\cdot\frac{(r-k)!}{(m-k)!\,(r-m)!} = \frac{r!}{k!\,(m-k)!\,(r-m)!}.$$

两边相等，且都等于三项式系数 $\frac{r!}{k!\,(m-k)!\,(r-m)!}$（把 $r$ 个元素分给三组）。

> **用途**：这是“选子集”锤子。乘积 $\binom{r}{m}\binom{m}{k}$ 里 $m$ 出现了两次，而右边 $m$ 只出现一次，对 $m$ 求和时会“掉出一个自由的 $\binom{r}{k}$”——这是化简 $\sum_m \binom{r}{m}\binom{m}{k}$ 型求和的唯一出路。

### (7) 二项式定理（binomial theorem）——第 7 条

$$\sum_k \binom{r}{k} x^k y^{r-k} = (x+y)^r$$

- **$r$ 为自然数**：$n$ 个因子 $(x+y)$ 相乘，每项选 $x$ 或 $y$，取 $k$ 个 $x$ 的方案数是 $\binom{n}{k}$。
- **$r$ 任意**：由武器 A 令 $z = x/y$、两边乘 $y^r$ 得到（形式幂级数恒等式）。

### (8) 平行求和（parallel summation）——第 8 条

$$\sum_{k \le n} \binom{r+k}{k} = \binom{r+n+1}{n}$$

**生成函数证明（前缀和 = 乘 $\frac{1}{1-z}$）**：由武器 D（把 $m$ 换成 $r$）：$\sum_k \binom{r+k}{k} z^k = \frac{1}{(1-z)^{r+1}}$。左边是对 $n$ 的前缀和，等价于母函数乘 $\frac{1}{1-z}$：

$$\sum_n \left(\sum_{k \le n} \binom{r+k}{k}\right) z^n = \frac{1}{1-z}\cdot\frac{1}{(1-z)^{r+1}} = \frac{1}{(1-z)^{r+2}}.$$

再用一次武器 D（$m = r+1$）提取系数：

$$[z^n]\frac{1}{(1-z)^{r+2}} = \binom{(r+1)+n}{n} = \binom{r+n+1}{n}.$$

### (9) 上指标求和（upper summation）——第 9 条

$$\sum_{0 \le k \le n} \binom{k}{m} = \binom{n+1}{m+1}$$

**生成函数证明**：先求单项母函数（下指标固定版本）：

$$\sum_{k \ge 0} \binom{k}{m} z^k = \frac{z^m}{(1-z)^{m+1}}.$$

同样地，前缀和 = 乘 $\frac{1}{1-z}$：

$$\sum_n \left(\sum_{0 \le k \le n} \binom{k}{m}\right) z^n = \frac{z^m}{(1-z)^{m+2}} = \sum_N \binom{N+m+1}{m+1} z^{N+m},$$

取 $[z^n]$ 即 $N = n - m$：

$$[z^n]\frac{z^m}{(1-z)^{m+2}} = \binom{(n-m)+m+1}{m+1} = \binom{n+1}{m+1}.$$

> 这一条就是俗称的**曲棍球棒恒等式（Hockey-stick identity）**：把 Pascal 三角的某一列从顶加到底，结果恰好在拐角处。第 8 条是它的“平移版”，两条互为变形。

### (10) 范德蒙德卷积（Vandermonde convolution）——第 10 条（重点）

$$\sum_k \binom{r}{k}\binom{s}{n-k} = \binom{r+s}{n}$$

- **证法一：生成函数（一行）**：由 $(1+z)^r \cdot (1+z)^s = (1+z)^{r+s}$，左边 $z^n$ 的系数是 $\sum_k \binom{r}{k}\binom{s}{n-k}$（武器 B：卷积 = 乘法），右边是 $\binom{r+s}{n}$，比较系数即得。
- **证法二：组合双计数**：从 $r$ 个男人、$s$ 个女人共 $r+s$ 人中选 $n$ 个人，右边直接是 $\binom{r+s}{n}$；左边按“选中 $k$ 个男人”分类求和。
- **证法三：常数项技巧（处理点积形式）**：若两个下指标相同而非互补：
  $$\sum_k \binom{r}{k}\binom{s}{k} = \mathrm{CT}_z\,(1+z)^r\left(1+\frac{1}{z}\right)^s = \mathrm{CT}_z\,z^{-s}(1+z)^{r+s} = \binom{r+s}{s}.$$

> **历史**：Vandermonde 于 1770 年代末发表；但中国数学家**朱世杰**在 1303 年《四元玉鉴》中已用到，故现代文献亦称 **Chu–Vandermonde identity（朱世杰–范德蒙德恒等式）**。

## 4. 三个实战范例

### 4.1 两个下指标相同的求和（点积型）

- **问题**：求 $S = \sum_{k=1}^{\min(x,y)} \binom{x}{k}\binom{y}{k}$。
- **解**：先把下指标翻成互补，再用范德蒙德卷积，最后去掉 $k=0$ 那一项：
  $$S = \sum_{k=1}^{\min(x,y)} \binom{x}{k}\binom{y}{y-k} = \binom{x+y}{y} - 1.$$
- **复杂度**：直接求和是 $\mathcal{O}(\min(x,y))$；用恒等式配合阶乘预处理只需 $\mathcal{O}(1)$ 查询。当 $x, y \ge 10^9$（配合 Lucas 定理）时这是唯一的活路。

### 4.2 分界点枚举（Table 169 的 (5.26)）

- **问题**：求 $T = \sum_{k=0}^n \binom{k}{r}\binom{n-k}{s}$。
- **解**：由 §3(9) 知 $\sum_k \binom{k}{r} x^k = \frac{x^r}{(1-x)^{r+1}}$，同理 $\sum_j \binom{j}{s} x^j = \frac{x^s}{(1-x)^{s+1}}$。两者相乘（下标 $k+j=n$ 的卷积）：
  $$\frac{x^r}{(1-x)^{r+1}}\cdot\frac{x^s}{(1-x)^{s+1}} = \frac{x^{r+s}}{(1-x)^{r+s+2}} = \sum_N \binom{N+r+s+1}{r+s+1} x^{N+r+s}.$$
  取 $[x^n]$（即 $N = n - r - s$）：
  $$T = \sum_{k=0}^n \binom{k}{r}\binom{n-k}{s} = \binom{n+1}{r+s+1}.$$

### 4.3 Catalan 数（从递推到通项）

- **递推**：$C_0 = 1,\; C_{n+1} = \sum_{k=0}^n C_k C_{n-k}$。
- **第一步（建模）**：设 $C(x) = \sum C_n x^n$。递推右边是卷积，于是
  $$\frac{C(x) - 1}{x} = C(x)^2 \iff C = 1 + xC^2 \implies C(x) = \frac{1 - \sqrt{1-4x}}{2x}.$$
- **第二步（提取）**：令 $w = C - 1$，则 $w = x(1+w)^2$，即 $w = x\phi(w)$，$\phi(w) = (1+w)^2$。由 **Lagrange 反演**（$[x^n]f(w) = \frac{1}{n}[w^{n-1}]f'(w)\phi(w)^n$）：
  $$C_n = [x^n]w = \frac{1}{n}[w^{n-1}](1+w)^{2n} = \frac{1}{n}\binom{2n}{n-1} = \frac{1}{n+1}\binom{2n}{n}.$$
- **第三步（检验）**：$n = 4$ 时 $\frac{1}{5}\binom{8}{4} = 14$ ✓。

## 5. 总结：生成函数做恒等式的三步

```text
① 建模   组合结构 / 求和式  ──→  母函数或函数方程
            · 下标和固定  →  相乘（卷积）
            · 下标相等    →  常数项 CT
            · 前缀和      →  乘 1/(1-z)
            · 出现因子 k  →  求导
② 求解   解方程（配方/部分分式）或停在隐式 w = xφ(w)
③ 提取   [z^n]：广义二项式定理 / 1/(1-z)^m 家族 / Lagrange 反演
```

- **第 7 条** = ① 的起点（母函数本体）；
- **第 1–6 条** = ③ 之前的整形工具（把式子变成能套模子的形状）；
- **第 8–10 条** = ③ 的结果（能直接读出的求和公式）。

> **记忆建议**：不必死背十条——背 **§2 的五个武器 + §3(10) 范德蒙德卷积**一条，其余七条都能在两三行内推出来！
